# as41 — Red remota (AS41)

Cliente de AS40 sobre un enlace **sin numerar**. Es el ejemplo más chico del laboratorio:
solo ilustra **BGP sin numerar** e **IPv4 con next-hop IPv6 (RFC 8950)**.

Sus prefijos (`41.0.0.0/16`, `2001:db8:41::/48`) **no tienen ROA**: en RPKI figuran como
"not found" y se aceptan igual. Sirve para contrastar con un prefijo "invalid" (que sí se
descarta).

## Configuración del enlace

```text
interface eth1
 ipv6 nd ra-interval 10
 no ipv6 nd suppress-ra
!
router bgp 41
 neighbor eth1 interface remote-as 40
```

No hay ninguna IP configurada en `eth1`: la sesión usa las link-local IPv6 que se
autoconfiguran. El `neighbor eth1 interface` reemplaza la IP del vecino.

## Para inspeccionar

```bash
./lab.sh vty as40 "show bgp ipv4 unicast 41.0.0.0/16"   # next-hop IPv6
./lab.sh vty as40 "show ip route 41.0.0.0/16"
./lab.sh vty a-b1 "show rpki prefix 41.0.0.0/16"         # "not found"
```

Ver la configuración: `configs/as41/frr.conf`.
