# as66 — Cliente de ISP-A (AS66)

Cliente de ISP-A, origen del **secuestro de prefijos**. Arranca anunciando solo su red
legítima (`66.0.0.0/16`). El secuestro de `50.0.1.0/24` (red de AS50) se activa aparte con:

```bash
./lab.sh escenario secuestro on
```

## Por qué puede secuestrar

ISP-A (`as10`) acepta **cualquier cosa** de este cliente: `route-map de-as66` no matchea
ningún prefix-list, solo setea `local-preference 200`. Sumado a que ISP-A no valida RPKI,
el prefijo robado se propaga hasta donde nadie lo descarte.

## Configuración

```text
interface lo
 ip address 66.0.0.1/32
 ip address 50.0.1.1/32        # la IP "robada"
!
ip route 66.0.0.0/16 Null0 250
ip route 50.0.1.0/24 Null0 250
!
router bgp 66
 no bgp ebgp-requires-policy
 no bgp default ipv4-unicast
 neighbor 10.0.8.2 remote-as 10
 address-family ipv4 unicast
  network 66.0.0.0/16           # el secuestro agrega: network 50.0.1.0/24
```

La ruta estática a `50.0.1.0/24 Null0` ya está "naileada" desde el arranque; el escenario
solo agrega el `network`.

## Para inspeccionar

```bash
./lab.sh vty as66 "show bgp ipv4 unicast"
./lab.sh vty as10 "show bgp ipv4 unicast 50.0.1.0/24"
```

Ver la configuración: `configs/as66/frr.conf`.
